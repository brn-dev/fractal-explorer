Hold Shift for smaller keyboard steps. Deep zoom uses MPFR reference orbits in a WebAssembly worker and WebGPU perturbation for Mandelbrot and Julia, accepting view widths down to 10⁻¹⁰⁰⁰⁰. This is a finite-precision renderer; zoom depth does not certify every pixel. Other formulas support widths down to 10⁻¹⁰ in the web edition. Pinch with two fingers to zoom on touch screens. All computation stays on this device; no rendering server is used.

Interior pixels are points that did not escape within your iteration budget. Increase iterations when deep regions appear solid.

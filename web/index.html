THE FRACTAL

zn+1 = zn² + c

Starts at z = 0; c is the pixel coordinate.

Syntax & examples

z is the current value. z1…z4 are the previous four values, also written z[n-1]…z[n-4]. Earlier history starts at zero.

Use + - * / ^ and parentheses. Functions: ln (or log), exp, sqrt, sin, cos, tan, sinh, cosh, abs, conj, re, im, pow. Constants: i, pi, e. Write multiplication explicitly: 5*z.

Functions use complex arithmetic and principal branches. Colors count iterations to escape; singularities and overflow count as escape. Custom formulas support view widths down to 10⁻¹⁰. GPU transcendental functions use native float precision.
